# 1.2.1

2026-11-28

- 편집기 설정에서 Original, Academic, Institutional, Ledger CV 양식과 컬러·흑백 모드를 각각 선택하고, 편집 중인 데이터로 결과를 미리 볼 수 있습니다.
- CV PDF의 머리말·꼬리말을 정리하고 하단 가운데에 페이지 번호를 표시합니다. 다음 쪽으로 이어지는 섹션에는 국문 `(계속)` 또는 영문 `(Cont'd)`를 붙여 제목을 다시 표시합니다.
- Original CV의 왼쪽 제목 열을 줄이고 사진의 모서리를 직각으로 표시합니다. PDF의 페이지 구분선을 정리하고 마지막 쪽의 본문 뒤에 진한 선을 표시합니다.
- **Web/CV 표시항목**에서 논문 타임라인, 공저자 선택 영역, 프로젝트 타임라인을 개별적으로 표시하거나 숨길 수 있습니다. 편집기의 표시 여부 문구를 **표시**와 **숨김**으로 통일했습니다.
- 프로젝트와 소프트웨어 카드가 같은 행에 놓이면 설명 길이에 맞춰 여백을 조정해 이미지 상단을 같은 높이에 표시합니다.
- 장학금 액수는 **총액**·**Total amount**, CV의 프로젝트 제목은 **프로젝트**·**PROJECT**로 표시합니다.
