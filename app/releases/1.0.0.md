# 1.0.0

2026-10-28

- 데이터 묶음의 공통 버전을 `data/version.json` 한 곳에서 관리합니다.
- 개별 JSON의 버전 표기를 정리하고 기존 파일도 읽도록 했습니다.
- 프로그램 업데이트 시 개인 데이터·`exports/`·도메인·Git 기록·로컬 실행 환경을 보존합니다.
- 개인 데이터에서 생성되는 서지·통계 파일을 최상위 `exports/`로 옮겼습니다.
- 인용수 조회·갱신 결과도 `exports/`로 분리했습니다.
- 릴리스별 변경 이력과 업데이트 경계 검사를 추가했습니다.
- 편집기에서 원본 버전과 필요한 릴리스 노트를 확인할 수 있습니다.
- 확인한 버전의 원본 커밋에서 프로그램 파일을 내려받아 백업·적용하고, 편집기 종료 후 실행 파일을 교체합니다.
- 다음 실행에서 미완료 업데이트를 확인하고 적용·되돌림·실패 결과를 표시합니다.
- 실행 파일에 빌드 버전을 기록하고, 개인 데이터를 유지하는 `--preserve-data` 릴리스 검사를 추가했습니다.
