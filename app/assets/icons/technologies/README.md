# Technology logo sources

All technology icons are SVG vector assets. The editor embeds identical copies
from `editor/cmd/editor/frontend/dist/assets/technologies/`.

- Programming-language and framework SVGs: [Devicon](https://github.com/devicons/devicon), except where noted below.
- Wails SVG: [Simple Icons](https://github.com/simple-icons/simple-icons).
- Excel SVG: Simple Icons v12.4.0.
- Rhino SVG: the `Rhinoceros` glyph from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/rhinoceros.svg).
- Grasshopper SVG: the original vector logo [published by David Rutten on the official Grasshopper forum](https://www.grasshopper3d.com/forum/topics/grasshopper-vector-logo?overrideMobileRedirect=1). The [Illustrator attachment](https://www.grasshopper3d.com/forum/attachment/download?id=2985220%3AUploadedFile%3A844548) was converted to SVG with the original paths and black fill preserved; the viewport is fitted to the artwork.
- HTML and CSS SVGs: the original wordmark assets from [Devicon](https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58/icons).
- Word SVG: Microsoft's current small-format [Office product icon](https://res.cdn.office.net/files/fabric-cdn-prod_20251117.001/assets/brand-icons/product/svg/word_16x1.svg).
- PDF SVG: the `file_type_pdf2` asset from [VSCode Icons](https://github.com/vscode-icons/vscode-icons/blob/5c19e38ab7f2eef4848f997dfd8301196a66a00b/icons/file_type_pdf2.svg).
- egui SVG: the original vector [application icon from the official egui repository](https://raw.githubusercontent.com/emilk/egui/main/crates/egui_demo_lib/data/icon.svg).
- EnergyPlus SVG: the vector symbol on page 2 of the [official DOE EnergyPlus presentation](https://www1.eere.energy.gov/buildings/publications/pdfs/corporate/ns/energyplus_update_nbm_0300608_1.pdf). The symbol's vector paths and colors are preserved; the separate wordmark is omitted for readability at icon size.

The logos remain subject to their upstream licenses and trademark policies.
