# Profile-Editor

Windows에서 `setup.bat`을 한 번 실행한 뒤 `build.bat`으로 빌드합니다.

- 소스 루트: `cmd/editor`
- 로컬 Go 툴체인, Wails CLI, 모듈 및 빌드 캐시: `runtime` (Git 제외)
- 배포 파일: 저장소 최상위의 `Profile-Editor.exe` (Git 추적 대상)

`setup.bat`은 시스템에 Go나 Node.js를 설치하지 않습니다. 공식 Go 배포본을
`runtime`에 내려받고, 같은 위치에 고정 버전 Wails v2 CLI와 의존성을 설치합니다.
프런트엔드는 별도 Node.js 빌드가 필요 없는 정적 파일로 구성됩니다. 프로필 탭에서는
기본 정보와 홈페이지 섹션의 순서·노출 여부를 편집하고, 사람·수상·논문·학술활동·
프로젝트·소프트웨어·게시판 탭에서는 각 JSON 항목을 수정·추가·삭제할 수 있습니다.
내용이 없는 홈페이지 섹션은 자동으로 숨겨지며, 항목을 추가하기 전에는 노출할 수
없습니다. 사람은 직접 순서를 바꿀 수 있고, 수상·논문·게시글은 홈페이지와 같은
기준으로 자동 정렬됩니다.
논문의 저자와 수상 관계는 ID 입력란 대신 사람의 이름·소속과 수상의 날짜·제목·기관을
확인하며 선택합니다.

프로필 탭의 장학 항목에서는 `amount.value` 숫자와 `amount.currency` ISO 3자리 통화
코드를 수정합니다. 장학에는 자유형 `details`를 사용하지 않습니다. 메인 페이지와 CV는
국문에서 KRW, 영문에서 USD를 목표 통화로 사용하며, 원통화와 다를 때만 표시 시점에
Frankfurter v2 rate endpoint의 환율을 지연 조회해 캐시합니다. 조회 실패 시 원금과
원통화를 표시하고, KRW·USD 금액은 모두 일의 자리에서 반올림한 십 단위로 표시합니다.
이 금액·통화 변경도 상단 `저장` 버튼을 누르기 전에는 JSON에 반영되지 않습니다.

학술활동 탭은 편집 서비스, 전문 서비스, 학술대회 서비스, 초청 발표, 리뷰를 각각
구분된 목록으로 관리합니다. 분류 헤더의 `+`로 해당 분류 항목을 추가하고, 항목의
위·아래 버튼으로 같은 분류 안의 순서를 바꿀 수 있습니다. 이 순서는 JSON 배열과
홈페이지 표시 순서에 그대로 반영됩니다. 학술활동 항목에는 관계용 `id`가 없으며,
항목이 없는 분류는 홈페이지에 나타나지 않습니다. 모든 분류가 비어 있으면 학술활동
영역 전체가 자동으로 숨겨집니다. 추가·수정·삭제·순서 변경은 편집기 안의 초안으로
유지되고 상단 `저장` 버튼을 눌렀을 때만 `data/academic_activities.json`에 반영됩니다.
이 파일의 최상위 형식은
`schema_version` 1과 `editorial_service`, `professional_service`,
`conference_service`, `invited_talks`, `reviews` 배열입니다. 학술활동을 메인 페이지와
CV 섹션으로 배치하는 `settings.json` 형식은 schema v7이며 양쪽 섹션 키는
`academic_activities`입니다. 각 활동의 `visible_in_CV`는 생략하면 `true`로 처리되며,
CV 탭의 compact 분류 목록에서 항목을 눌러 포함 여부를 바꿉니다. CV에 선택된 활동이
없으면 학술활동 CV 섹션은 자동으로 숨겨집니다.

리뷰는 완료일을 기억할 수 있도록 `completed_dates`에 `YYYY-MM-DD` 날짜를 하나씩
저장합니다. 편집기에서는 이 완료일 목록을 추가·수정·삭제하며, 숫자형
`review_count`를 직접 입력하거나 JSON에 저장하지 않습니다. 홈페이지의 리뷰 횟수는
`completed_dates` 배열 길이로 자동 계산됩니다.

소프트웨어의 기술은 홈페이지에서 아이콘을 지원하는 목록에서 선택합니다. JSON에서 직접
추가한 미등록 기술도 삭제하거나 이름을 바꾸지 않으며, 편집기에서는 `아이콘 미지원`으로
구분해 그대로 유지합니다.

CV 탭에서는 CV 섹션의 순서·노출 여부와 각 항목의 포함 여부를 따로 정합니다. 항목의
`visible_in_CV`가 없으면 기본적으로 노출되며, CV 탭에서 항목을 누르면 숨김·노출 상태가
전환됩니다. 이 설정을 포함한 모든 변경은 상단 `저장` 버튼을 눌렀을 때만 함께
반영됩니다.

Explorer에서 드롭한 사진은 OS 임시 폴더에만 보관되다가 저장할 때
`data/media`로 복사됩니다. 저장하지 않은 변경이 있으면 창을 닫기 전에 경고가
표시됩니다. 항목에서 미디어를 제거하거나 항목을 삭제해도 공유 미디어의 데이터
유실을 막기 위해 기존 `data/media` 파일은 자동 삭제하지 않습니다.

프로필·프로젝트·소프트웨어·게시판의 미디어 썸네일을 누르면 원본을 팝업으로
확대해 볼 수 있습니다. Esc 또는 × 버튼으로 닫으면 기존 편집 위치로 돌아옵니다.
저장 전 드롭한 이미지도 볼 수 있으며, 미리보기는 데이터를 저장하거나 변경하지 않습니다.

`data/*.json`은 편집기 내부 데이터의 사본이 아니라 홈페이지와 CV가 직접 읽는
원본입니다. 따라서 편집기를 완전히 닫은 상태에서는 JSON을 직접 수정해도 되며,
다음 실행 때 파일의 최신 내용과 ID를 다시 읽습니다. 사람·수상·소프트웨어·프로젝트
테마·논문 주제 ID를 직접 바꿀 때는 `^[a-z0-9]+(?:-[a-z0-9]+)*$` 형식을 지키고
`author_ids`, `award_id`, `theme`, `topic`의 관련 참조를 모두 함께 변경해야 합니다.
프로젝트, 논문과 학술활동 항목 자체에는 의도적으로 ID가 없습니다.

홈페이지와 CV에는 `data/*.json` 변경이 빌드 없이 반영됩니다. 다만
`app/generated/`의 내보내기 파일과 데이터 보고서는 파생 결과이므로 해당 결과까지
갱신하려면 `app/tools/build.bat`을 실행해야 합니다.
